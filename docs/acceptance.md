## 3. 暂不纳入本次验收

- 线上 Python、PostgreSQL、Redis、对象存储部署
- 真实第三方平台发布授权
- 多租户计费与团队权限
- 专业视觉模型的自动打分
- 大规模并发压测
- 生产级告警与长期指标看板

## 4. 演示注意事项

- 生图依赖第三方额度和网络，正式演示前确认账户可用
- 如需稳定答辩，可使用仓库中已有宠物店完整案例
- 在线站点当前为访问受限版本
- 在线 Python 服务未接入时，知识库会明确提示服务尚未连接
- 简历中应写“完成本地全栈实现与部署配置”，不要写成所有数据服务均已生产上线
